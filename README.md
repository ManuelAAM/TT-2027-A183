# TT-2027-A183
El presente Trabajo Terminal propone un sistema de monitoreo y análisis de redes de área local en entornos académicos. Medirá latencia, pérdida de paquetes y disponibilidad mediante pruebas automatizadas para identificar posibles fallos de conectividad, sugerir acciones iniciales y almacenar registros históricos para apoyar su diagnóstico.
